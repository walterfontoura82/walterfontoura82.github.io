# Portfolio de Walter Fontoura

Portfolio profesional de Walter Fontoura centrado en Cloud, DevOps e infraestructura.

## Estructura
- `index.html`: contenido principal del sitio.
- `style.css`: estilos visuales y diseño responsivo.
- `script.js`: archivo de soporte para interacciones futuras.

## Visualización
Abre `index.html` en el navegador o sirve la carpeta con un servidor local sencillo para revisar la presentación.

## Objetivo
Mantener una página clara, en español y con información profesional verificada, sin inventar experiencias ni resultados.
